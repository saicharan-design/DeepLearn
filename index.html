How it works

Built around what educators worry about: weaker critical thinking, less group learning and shortcut learning.

Ask

Type your doubt and name the topic.

Hint first

Start small. Ask for a bigger hint if you need one. The server blocks the full solution until you write an attempt.

Explain it back

Restate the idea in your own words, then answer a “why” follow-up.

Group quiz mode is on the roadmap. It is not built yet.

Teachers see where students struggle

The class view lists the most-asked topics with counts only. It never shows what students typed. Counts reset when the server restarts.
